# はじめる

## インストール

```bash
git clone git@github.com:itwillrain/screen-spec.git
cd screen-spec
npm install
```

## 検証する

`screen-spec validate` は YAML の設計書を検証します。

```bash
npm run validate examples/pages/users/edit.screen.yaml
```

複数のscreenとtestDataを同時に渡すと、画面遷移先、`testData.screen`、fixtureのparam・field、
文書間のfixture ID重複も横断検証します。

```bash
npm run validate examples/pages/users/edit.screen.yaml examples/pages/users/list.screen.yaml examples/fixtures/users/edit.fixtures.yaml
```

妥当な場合:

```
✓ examples/pages/users/edit.screen.yaml is valid
```

不正な場合は、段（`raw` / `resolve` / `resolved`）ごとの診断が表示され、終了コードは `1` になります。

```
✗ examples/fixtures/invalid/screen.screen.yaml is invalid
    [raw] /screen/id must match pattern "^[a-z][a-z0-9]*(-[a-z0-9]+)*$"
    [raw] /screen/fields/Email must match exactly one schema in oneOf
```

## テスト

```bash
npm test        # vitest
npm run typecheck
```

## テスト項目を出力する

```bash
npm run testgen -- examples/pages/users/edit.screen.yaml \
  --test-data examples/fixtures/users/edit.fixtures.yaml \
  --format markdown
```

`--format csv`でCSV、`--output <file>`でファイルへ保存できます。`--test-data`は省略可能です。
