# Components

Componentは、`components`配下に名前付きで登録された、取得元に依存しない再利用可能な完全な仕様契約です。実際の参照回数ではなく、登録された再利用意図によってComponentとなります。
OpenAPI の `components` に相当します。定義名は **PascalCase**（[命名規則](/concepts/naming)）。

同じ意味とUI契約を持つComponentは取得元が異なっても再利用できます。意味または確定仕様が異なる場合は、見た目が同じでも別Componentとして定義します。継承・差分合成は行いません。

## サブセクション（v0.1）

| セクション | 定義する部品 |
|---|---|
| `components.validations` | [Validation](/reference/validation) |
| `components.fields` | [Field](/reference/field) |
| `components.options` | [Options](/reference/options) |

## 例

```yaml
specVersion: "0.1"
components:
  validations:
    Required:
      rule: required
      message: 必須項目です
    EmailFormat:
      rule: pattern
      value: "^[^@\\s]+@[^@\\s]+\\.[^@\\s]+$"
      message: メールアドレスの形式が正しくありません
  fields:
    EmailField:
      label: メールアドレス
      type: email
      required: true
      validations:
        - $ref: "#/components/validations/Required"
        - $ref: "#/components/validations/EmailFormat"
  options:
    RoleOptions:
      - { value: admin, label: 管理者 }
      - { value: editor, label: 編集者 }
      - { value: viewer, label: 閲覧者 }
```

コンポーネント同士も `$ref` で参照できます（上の `EmailField` が `Required` を参照）。
参照は純粋参照で、兄弟キーは書けません（[`$ref` ガイド](/concepts/refs)）。
