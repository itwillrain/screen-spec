# Field

画面上の 1 項目。`fields` マップの値、または `components.fields` の定義として使います。

## フィールド

| キー | 型 | 必須 | 説明 |
|---|---|---|---|
| `label` | string | ✔ | 表示ラベル |
| `text` | string | | ボタンやラベルなどに表示する文言 |
| `eventId` | string | | このUI要素が発火する`screen.events`のキー |
| `type` | enum | ✔ | 項目型（下記） |
| `required` | boolean | | 必須かどうか |
| `default` | any | | 既定値（`type` / `options` に整合。不一致は warning） |
| `placeholder` | string | | 未入力・未選択状態で表示する案内文 |
| `width` | enum | | 表示幅ヒント `full` / `half` / `third` |
| `visibleWhen` | string | | 表示条件式（例 `fields.role == "admin"`） |
| `enabledWhen` | string | | 編集可否の条件式（`true` で編集可） |
| `validations` | ([Validation](/reference/validation) \| $ref)[] | | 検証ルール |
| `options` | [Option](/reference/options)[] \| $ref | | 選択肢（`select` などで使用） |
| `permission` | [Permission](/reference/permission) | | 項目レベルの権限 |

## 表示条件（visibleWhen）

`visibleWhen` は条件式で、`true` のときにフィールドを表示する意図を宣言します（UI 実装は伴いません）。

```yaml
altEmail:
  label: 予備メール
  type: email
  visibleWhen: fields.role == "admin"
```

- 比較演算子 `==` `!=` `>` `<` `>=` `<=`、論理 `&&` `||`（括弧なし・左結合）
- 参照は `fields.X` / `screen.route.Y`、リテラルは文字列/数値/`true`/`false`/`null`
- 構文エラー・未定義参照は **warning**

## 標準Input Contract

FieldのvalueはField自身の標準状態です。`select`と`radio`は追加Inputとして動的`options`と`loading`を受け取れます。取得元との接続は[Field Bindings](/reference/field-bindings)で記述します。Componentごとの`inputs`宣言はありません。

## `type` の値

`text` / `textarea` / `email` / `number` / `date` / `select` / `checkbox` / `radio` / `button` / `label`

## ボタンとラベル

入力欄以外のUI要素も`fields`へ記述します。`label`は設計上・アクセシブルな名称、`text`は実際の表示文言です。`eventId`は同じ画面の`events`キーを参照し、event側の`target`にはfieldキーを指定します。

```yaml
helpText:
  label: 入力案内
  type: label
  text: 必須項目を入力してください。

submitButton:
  label: 保存ボタン
  type: button
  text: 保存する
  eventId: submit

events:
  submit:
    trigger: click
    target: submitButton
    from: editing
    to: submitting
```

未定義の`eventId`、またはfieldキーと`event.target`の不一致はwarningです。

## 例

```yaml
name:
  label: 氏名
  type: text
  required: true
  validations:
    - $ref: "./common.yaml#/components/validations/Required"
    - rule: maxLength
      value: 50
      message: 50文字以内で入力してください
```

`$ref` で項目そのものを参照することもできます（純粋参照）。

```yaml
email:
  $ref: "./common.yaml#/components/fields/EmailField"
```
