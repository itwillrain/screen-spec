# UI Components

UI Componentは、Pagination、DataTable、Header、Sidebar、Footerのような複数のFieldを名前付きでまとめる、取得元と実装に依存しないComponentです。内部要素にもScreen直下と同じField定義を使います。

## Component定義

`components.ui`へPascalCaseで登録し、`fields`へFieldを定義します。専用のInputs、Events、Partsはありません。操作を通知するFieldには`eventId`を指定します。

```yaml
components:
  ui:
    Pagination:
      name: ページネーション
      description: 一覧の表示範囲を移動する
      fields:
        previous:
          label: 前のページ
          type: button
          text: 前へ
          eventId: pageChange
        pageNumbers:
          label: ページ番号
          type: list
          eventId: pageChange
        next:
          label: 次のページ
          type: button
          text: 次へ
          eventId: pageChange
        pageSizeSelector:
          label: 表示件数
          type: select
          eventId: pageSizeChange
        summary:
          label: 表示範囲
          type: label
```

## Component Instance

Screenでは`ui`へInstanceを定義し、内部Fieldの値・属性と`eventId`を画面固有の契約へ接続します。

```yaml
screen:
  ui:
    userPagination:
      component:
        $ref: "./common.yaml#/components/ui/Pagination"
      bindings:
        summary.currentPage: { source: data.userPage }
        summary.totalCount: { source: data.userTotal }
        pageSizeSelector.options: { value: [20, 50, 100] }
        pageNumbers.loading: { source: api.listUsers.loading }
      events:
        pageChange: changePage
        pageSizeChange: changePageSize
```

全画面で共通の固定値はComponent内Fieldの`default`へ定義し、ScreenのBindingには画面固有の値だけを記述します。

Binding keyは`fieldId`または`fieldId.property`です。値には`source`または固定`value`の一方を指定します。先頭の`fieldId`はComponentの`fields`に存在する必要があります。Event Mapping keyは内部Fieldに定義された`eventId`、値はScreen Event IDです。同じ`eventId`を複数Fieldで共有できます。

## 画面要素の配置と表示

`layout.sections[].items`へScreen直下のFieldとComponent Instanceを定義順に配置します。Sectionは平坦で、`region`に`header`、`sidebar`、`body`、`footer`を指定します。入れ子Regionは扱いません。

```yaml
layout:
  sections:
    - { id: header, region: header, items: [{ component: appHeader }] }
    - id: results
      region: body
      items:
        - field: keyword
        - component: userTable
        - component: userPagination
    - { id: footer, region: footer, items: [{ component: appFooter }] }
```

同じInstanceを複数配置せず、配置ごとに別Instance IDを定義します。既存の`sections[].fields`はv0.1の互換形式として受理します。ViewerではComponent Instanceを開閉可能なチャンクとして表示し、内部Fieldを`instanceId.fieldId`の通常のField行へフラットに展開します。
