# Layout

`screen.layout`は、ピクセルや実装フレームワークに依存せず、Section、region、定義順によって画面構造を表します。FieldやComponent Instanceを再定義せず、キーで参照します。

## LayoutSection

| キー | 型 | 必須 | 説明 |
|---|---|---|---|
| `id` | string (camelCase) | | Section識別子 |
| `title` | string | | 見出し |
| `region` | enum | | `header` / `sidebar` / `body` / `footer`（既定`body`） |
| `columns` | integer (1–4) | | 列数ヒント（既定1） |
| `items` | `LayoutItem[]` | ✔ | FieldとComponent Instanceの順序付き配置 |
| `fields` | string[] | | v0.1互換のField配置 |

Sectionは平坦です。入れ子Regionは定義しません。ViewerはSectionとItemの記述順をScreen Outlineとして維持します。

## LayoutItem

Fieldは`field`、UI Component Instanceは`component`で参照します。1つのItemに両方は指定できません。

```yaml
screen:
  layout:
    sections:
      - { id: header, region: header, items: [{ component: appHeader }] }
      - { id: navigation, region: sidebar, items: [{ component: adminSidebar }] }
      - id: results
        title: 検索結果
        region: body
        columns: 2
        items:
          - field: keyword
          - component: userTable
          - component: userPagination
      - { id: footer, region: footer, items: [{ component: appFooter }] }
```

同じComponent Instanceを複数箇所へ配置せず、配置ごとに別Instance IDを定義します。`fields`は既存仕様との互換形式として受理しますが、新規記述では`items`を正規形とします。

## 診断

- 未定義Fieldの配置 → warning
- 未定義Component Instanceの配置 → error
- Layoutに配置されていないField → warning
- Layoutに配置されていないComponent Instance → warning
