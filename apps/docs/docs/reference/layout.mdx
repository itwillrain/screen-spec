# Layout

画面のデザインを**言語レベル**で表現する構造。`screen.layout` に置きます。特定の UI フレームワークに
依存しないよう、ピクセル単位のスタイルではなく **セクション・列・幅ヒント** で構造を表します。

フィールドはここで再定義せず、**キー参照**で配置します（[コレクションはマップ](/concepts/collections)）。

## フィールド

| キー | 型 | 説明 |
|---|---|---|
| `sections` | `LayoutSection[]` | セクション（項目グループ）の配列 |

### LayoutSection

| キー | 型 | 必須 | 説明 |
|---|---|---|---|
| `id` | string (camelCase) | | セクション識別子 |
| `title` | string | | 見出し |
| `region` | enum | | 配置領域 `header` / `body` / `footer` / `sidebar`（既定 body） |
| `columns` | integer (1–4) | | 列数（既定 1） |
| `fields` | string[] | ✔ | 配置するフィールドキー |

各フィールドには `design`（[デザイン参照](/reference/design)）も指定でき、画面全体の `screen.design`
とは別に項目単位のモックアップ/リンクを持てます。

各フィールド側には表示幅ヒント `width`（`full` / `half` / `third`）を指定できます。

## 例

```yaml
screen:
  id: user-edit
  name: ユーザー編集画面
  layout:
    sections:
      - id: basic
        title: 基本情報
        columns: 2
        fields: [name, email, altEmail]
      - id: authz
        title: 権限
        fields: [role]
  fields:
    name:
      label: 氏名
      type: text
      width: half
```

## 診断

- `sections[].fields` が未定義フィールドを配置 → **warning**
- `layout` があるのにどのセクションにも配置されていないフィールド → **warning**

ビューアは各画面の「レイアウト」セクションで、列グリッドと幅ヒントを可視化します。
